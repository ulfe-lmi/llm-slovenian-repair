## 3. Explicit local choices, not universal OAP rules

The following implement the owner's request or this project's bootstrap profile;
the attached chapters do not prescribe these exact filenames, numeric budgets
or transport bytes:

- Minimal repository AGENTS router; separate dense coding/full strategic files.
- Three non-nested directories; one canonical current full PLAN/ARCHITECTURE/CRITICAL
  source; controlled strategic constitution copy and immutable input archives.
- Context byte/token budgets, transitive read-set manifest and distillation map.
- Exact `OK` FIFO framing, wrapper-owned control read and report-only `SELF` commit.
- Three-digit objectives and ordered suffixes a–z then aa–zz, all on one numeric
  objective's PR; no ID advance on process failure.
- Strict physical-EOF byte-preserving critical appends and separately named exact
  mitigation-update field. These realize append-only-in-spirit without rewriting.
- 56 initial objectives and explicit demonstrator/MVP/service audit checkpoints.
- Setup versus operational tmux modes, separate role homes and inactive handoff.
- Structural validators that explicitly do not pretend to prove semantic fidelity,
  D1 truth, human authorization or independence merely from a file label/hash.

The previously inspected `ulfe-lmi/slaif-local-coding` implementation informed
separate workspaces, compact architecture, fresh coding rounds and the protocol
precedents. Its reviewed root AGENTS was a coding constitution, **not** the newly
requested minimal router. Its snapshot is not a claim about the current branch or
live host, and none of its Qwen-adapter product laws replaces this repair plan.

Previously supplied Connect/ZAP-IT archives informed setup/role/OAP patterns. They
are not needed or shipped inside this ZIP. Their application-specific requirements
(SSH/Chrome/Slurm/GaMS or vision/GPU-index policies) are not imported. All necessary
workflow requirements are specified locally in this package.

## 4. Corrections to obsolete bootstrap inputs

This version replaces the previously generated bootstrap instructions/contracts;
do not mix them with older files in one temporary directory.

- Root operational AGENTS is now a router, not the coding constitution.
- Coding no longer has mandatory full PLAN/architecture/CRITICAL startup reads.
- Strategy gets a full constitution and reads canonical full product sources.
- No separately editable private architecture/plan/critical mirrors.
- Canonical DHA entry labels and exactly four human disposition values; SUPERSEDED
  is not an additional human decision.
- Mandatory H/A/E/I/C provenance, forced D1 duty, dual gates, logical recovery,
  independent closure audit and explicit semantic-verification limits.
- Suffix grammar is now explicitly a–z, aa–zz; old a–z-only rules are superseded.
- Architecture 1.1 changes governance §1 and §§17–21 only. Product §§2–16 are
  unchanged from supplied architecture 1.0; PLAN remains byte-identical.

This package supplies specifications for a powerful generator to build the real
bootstrap. It does not claim that a working helper implementation, live-model
acceptance, linguistic benchmark, independent audit or human authorization already
exists. The generator's receipt must establish its actual installed/tested state.
