# Source identity and role distinction

Root `PLAN.md`, `ARCHITECTURE.md` and `CRITICAL.md` preserve the supplied bytes
at bootstrap. PLAN is protected; the current architecture evolves only under
controlled current-source/projection changes; CRITICAL grows by exact
authorized EOF append. The historical `docs/bootstrap/` snapshots are immutable
reference inputs, not competing current law. The original bootstrap AGENTS file
is archived as `BOOTSTRAP-GENERATOR.md` so no bootstrap-role instruction is
inherited by the current roles.

- Source mapping and exact hashes:
  [bootstrap source lock](../oap/bootstrap-sources.lock.json).
- Source snapshots retain original-context links and citations unchanged; such
  historical links are not active navigation and do not assert current web
  availability.
- The current governance
  [distillation map](../oap/governance/DISTILLATION-MAP.md) distinguishes source
  doctrine from project implementation choices (router, budgets, paths, OK/SELF
  framing, suffix and update grammar).
- No snapshot checksum proves authorization, semantic fidelity or product
  acceptance.
