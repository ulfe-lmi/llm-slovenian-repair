# Project decision policy

D0: choose/test/document ordinary reversible module layout, queue implementation
or scoped dependency after compatible rights. Failed tests, missing corpus/auth,
weak statistical support and ordinary bugs are evidence work, not judgment debt.

D1: strategy MUST investigate and provisionally choose a consequential contained
option, compare credible alternatives, stage/reversibility/blast radius, mitigate/
test and state strongest counterargument. All five required conditions: governing
law/evidence unresolved; investigated materially different alternatives requiring
choice; material security/privacy/auth/data/trust/exposure/release consequences;
safe testable provisional path without D2 crossing; plausible competent human
rejection/change before exact gate. Exclude TODO/style/ordinary dependency/
speculation/low-impact/repeated dilemma. Keep uncertainty explicit; no routine
human interruption simply because a reversible choice feels uncomfortable.

D2: real sensitive data under unapproved trust, production or deploying merge,
irreversible data, credential changes, real exposure/network/security posture,
protected Qwen changes, legal obligations or redefinition of human intent. Analyze
and recommend, stop real action; safe isolated preparation remains separately scoped.
Unknown rights need investigation/permitted alternative, not a CRIT-derived license.
Lowering strict acceptance past independent evidence changes product agreement.

Strategy authors exact canonical entry/ID. Coding reports candidates or appends
ordered bytes before implementation SHA. All five attestation is declarative.
Mitigation/supersession remains pending. Human dispositions exactly ACCEPTED,
REJECTED, CHANGE REQUIRED, DEFERRED; latest attributable verified ACCEPTED only
clears registered gate. A name in Markdown does not authenticate. Review aggregate
risk at gates; none of this grants independently missing deployment authority.
