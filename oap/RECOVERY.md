# Durable recovery

Resolve both actual pipe paths through OAP_FIFO_HOME. A strategic workspace on
the explicitly selected sync mount contains regular files only. Never reconstruct
a missing pipe as an empty regular file or signal a stale pre-relocation path.

No active: inactive/wait outside model. Empty/malformed active: invalid, no guessing.
Consumed signal + no report: explicit recovery, same ID/branch/PR and first unfinished
criterion. An interrupted a with PR reuses it, never creates duplicate. Record reason
in private workorders before deliberate --resume-id and re-signal. Process/context/
model/provider/host replacement changes no objective/suffix/authority.

Local report, remote unverified: reconcile/finish publication without rewriting
immutable report. Remote final report, lost notification: strategic review; duplicate
signal suppresses coding. Publication crash between order write and active update:
identical still-unresolved retry may finish activation; conflicting/completed order
cannot reactivate. Critical append crash: compare full prior/payload; exact replay
no-op, partial/stale history stops. No seed reconstruction of missing CRITICAL.

Nonzero role exit or inconsistent publication records bounded private incident,
never automatic restart or false OK. Pending required CI means wait/recheck, no
busywork/suffix. Explicit quit returns to shell; no watchers/services/autostart.
Read current GitHub/OAP before relying on handoff. Preserve observations; supersede
incorrect interpretations explicitly. Private logs contain status/SHA/counts only.
