### D1-1: Fix mechanism for the mid-document raw-block defect

Dilemma: the 008-f hidden acceptance found 458 B (20 documents) of
mid-document YAML-style and HTML/XML fragment exposure. Two materially
different fix families exist: (a) extend the residual semantic layer
(the designated home for machine-significant content Markdown parsing
cannot distinguish) with the bounded classes needed; (b) a structural
pre-pass over the raw source that detects and force-protects mid-document
raw blocks outside the parser model.

Governing authority: the 2026-09-17 human architecture decision
(parser first, parser-approved Text, narrow residual recognizer; no
ever-growing regex grammar over the complete raw document; the residual
class list explicitly includes YAML/TOML/config-like text) and the 008-f
order's named scope (which permits either family but records the
residual class first).

Evidence: 008-f defect attribution (data-free): all 20 documents are
template T10-randomized, category structured, families
structured-yaml (348 B) and structured-xml (110 B), 19-24 B each;
mechanism is a recognized CommonMark dialect limitation (mid-document
YAML blocks and non-block-start-tag HTML/XML fragments parse as
paragraph text), not a parser bug; the existing yaml-toml-config class
requires >= 2 consecutive key-value lines or a section header and does
not cover the exposed single-line / nested shapes; no residual class
covers non-HTML-recognized tag fragments. Zero exposure on the dev set
(the corner case was placement-specific).

Alternatives compared: (a) residual classes - contained inside the
frozen architecture; pure functions of parser-approved candidate-prose
text; verified by the existing dev corpus plus a new visible dev defect
batch and the new hidden acceptance set; small blast radius (two bounded
recognizer additions); reversible (policy versioning: v3 supersedes v2,
v2 bytes immutable in-tree). (b) structural pre-pass - reintroduces
raw-document scanning that the architecture decision rejects; larger
blast radius (event-order interaction, CRLF/Unicode boundary handling
outside the parser model); harder to bound and to test in isolation.

Stage suitability / reversibility / blast radius: research and
evaluation phase; the new sealed hidden set is the acceptance
instrument; the fix must be validated without any 009 data; if the
residual classes misfire, the dev regression (committed before any
hidden evaluation) and the new hidden set both catch it, and a further
suffix re-bounds it.

Choice: (a) - (1) extend yaml-toml-config coverage for the exposed
YAML-style shapes under the strictness contract in Scope item 4; (2) add
one new residual class, xml-fragment, for HTML/XML tag fragments the
parser dialect does not recognize as HTML. No structural pre-pass.

Mitigation and tests: strict trigger conditions (Scope item 4); a new
visible dev defect batch with explicit prose controls (time expressions,
inequality angle brackets, label-style Slovenian sentences); committed
dev regression with actual loss reported by container before any hidden
evaluation; new hidden set acceptance; e2e invariants 1-7 unchanged in
meaning; focused positive and negative tests for both sub-fixes.

Serious strongest counterargument: a regex-based recognizer on prose is
exactly the ever-growing-regex-grammar pattern the architecture rejects;
each new defect class grows the residual layer, and if LLM output
contains many such classes the residual layer silently becomes the
second parser it was meant to replace. Response: the residual layer's
scope is semantically bounded to the human-named machine-significant
categories (TeX forms, bare JSON/YAML/TOML/config, shell, paths,
environment variables, identifiers, machine-significant numbers, bare
URLs); the defect classes (config-like blocks, non-HTML tag fragments)
are inside that named scope; the additions are strict and conservative;
the dev regression and the new hidden set measure actual prose
over-suppression, which is reported as actual loss, not hidden; and if
the residual surface ever grows beyond comprehension, that signal is
itself the trigger for an architecture review - it is not present after
two bounded, scoped additions.

Judgment debt: registered; cleared only by a final objective-008 PASS
verdict on the new hidden set (carried forward with this round's report
otherwise).

### D1-2: Refined adjudication instrument

Dilemma: the 008-f adjudication stopped fail-closed at case 4 of 70
(invalid verbatim-quote tiling on two consecutive attempts under the
predeclared at-most-one-retry policy). The 008-f order names completion
"with a strategy-devised refined instrument". The instrument interface
must be chosen now, before any case is re-adjudicated.

Governing authority: the 2026-09-17 human decision (independent
adjudication; frozen annotation guide; AMBIGUOUS explicit; independent-
review reconciliation; implementation-free) and the 008-f order scope
item 3.

Evidence and root cause: the 008-f revised interpretation
(C-EVIDENCE-01): model-side tiling anomaly specific to the comparison-
table case (repeated identical cells make verbatim quote tiling
ambiguous; start_text not found sequentially), not a driver defect
(17/17 prior cases valid, 2/2 prequalification pilots valid, 8/8
synthetic extraction/resolver self-tests correct and fail-closed). The
verbatim-quote contract is structurally fragile for repetitive content;
loosening the retry budget or the quote contract would tune the
instrument to pass and contaminate it.

Alternatives compared: (a) relax the tiling contract / retry budget -
rejected (instrument tuning to pass; the same failure class can recur);
(b) line-indexed range classification - the driver numbers the physical
lines of each response; the model returns an exact partition of line
ranges with the guide's category per range; mapping is mechanical (no
text lookup), so the observed failure mode is structurally eliminated;
(c) per-line individual calls - 1,000+ calls, no validity gain over
batched ranges.

Choice: (b). Contract: fresh context per case; prompt contains the
frozen guide (bytes unchanged, sha256
e65816ddda65343e45b9c0b9fa112b8e18eea19b17310a997cff87b9a200eb5e) plus
the response with each physical line numbered 1..N (CRLF normalized for
numbering; normalization disclosed per case); output = ordered list of
{start_line, end_line, category, ambiguous} covering 1..N exactly once,
categories from the guide vocabulary; mechanical validation (partition
check, vocabulary check, in-bounds check); at most one retry on
validation failure, then the case is recorded ADJUDICATION_FAILED (no
label fabricated); reconciliation per the frozen guide (second pass over
all AMBIGUOUS plus a deterministic 20 percent sample, recorded seed);
all 70 cases run under the v2 instrument (the 17 v1 raw tilings are
preserved observations, never labels; cross-instrument agreement on the
3 cases with valid v1 tilings is disclosed as a sanity statistic); one
label file per case written to the private root; the committed
content-free manifest covers the 18 v1 raw files plus all v2 label
files (case IDs + sha256 + size only).

Mitigation and tests: mechanical validation before any label write;
fail-closed per case; the committed 008-f driver stays byte-identical
(the v2 driver is a new committed file); synthetic self-tests of the
partition validator (data-free, zero model calls); adjudication
statistics (model identity, call count, AMBIGUOUS count, reconciliation
outcomes) in the report.

Serious strongest counterargument: line-indexed granularity is coarser
than the span-level reading the guide's decision procedure assumes, and
forcing spans onto whole lines can misclassify lines that mix prose and
machine content. Response: the guide's categories are span categories
and a line range is a span; the naturalistic responses are
line-structured Markdown where the protection-relevant spans align with
lines (paragraphs, list items, table rows, code fences, formula lines);
mixed lines are exactly what the AMBIGUOUS label plus reconciliation
exists for; the naturalistic axis is secondary to the machine-known
mashup corpus (human 2026-09-17), so bounded granularity loss is
accepted and disclosed.

Judgment debt: registered; cleared only by completed adjudication
(70/70 labels or the named CONDITIONAL state) with reconciliation
statistics in the report.
